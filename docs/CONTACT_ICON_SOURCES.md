# Contact SVG sources

The portfolio uses established SVG icons rather than generated approximations:
- **GitHub, Discord and Steam:** Simple Icons project, https://github.com/simple-icons/simple-icons , paths from `icons/github.svg`, `icons/discord.svg`, `icons/steam.svg`.
- **Email:** Bootstrap Icons, https://github.com/twbs/icons , `icons/envelope-fill.svg`.

All are rendered consistently with the portfolio's `currentColor` styling. Discord and Steam destination placeholders are deliberately disabled until real profile links are supplied. Keep upstream attribution/license details with the design system.
